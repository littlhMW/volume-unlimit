# 程序音量增益

这是一个只针对选定程序的 Windows 小面板。它使用 Windows 10 版本 21H2（内部版本 20348）及更高版本提供的 **Application Process Loopback** 捕获目标程序，再把 PCM 音频放大后送回当前默认播放设备。回环接口由随程序携带的 MIT 许可原生组件封装，不安装驱动。

## 使用

1. 双击 `VolumeBoost-Setup.exe`，安装器只写入当前用户的 `AppData\Local\Programs\VolumeBoost`，不需要管理员权限，也不安装虚拟声卡或 Equalizer APO。
2. 从桌面快捷方式打开“程序音量增益”。先让目标程序播放声音，程序会自动列出它。
3. 在列表中点击选择一个或多个程序，把“真正增益”设为 `500%`（约 5 倍振幅），点击“启动增益”。停止时点击同一个按钮即可恢复所选程序原音量。

普通独立音量仍是 Windows 的 0–100%；“真正增益”是重新捕获并播放后的 100–1000%。面板会在后台刷新会话列表，但不会因此停止正在运行的增益。

## 清理

在“设置 → 应用 → 已安装的应用”中卸载，或运行安装目录中的 `VolumeBoost-卸载.exe`。卸载器会结束本程序、删除桌面和开始菜单快捷方式、删除用户级卸载项及整个安装目录，不会触碰系统音频设备、Equalizer APO 或其他程序。

## 限制与安全

- 500% 是采样振幅约 5 倍（约 `+13.98 dB`），不是扬声器功率的 5 倍；超过满幅的部分会削波。
- 重新播放会带来几十到几百毫秒延迟。ASIO、WASAPI 独占模式、受保护音频或不支持的旧版 Windows 可能无法捕获。
- 增益目前针对当前默认多媒体输出设备；如果程序被单独路由到其他输出设备，需先切回默认设备。
- 第一次测试前请先把耳机、音箱或功放的物理音量调低。极端增益可能刺耳并损伤听力或设备。
